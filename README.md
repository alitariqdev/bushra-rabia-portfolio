# Bushra Rabia Portfolio

A responsive one-page portfolio for Bushra Rabia, focused on IT infrastructure, cloud, security, identity, and governance leadership.

The downloadable résumé is included in `assets/` with the phone number removed for public use.

## Preview locally

Open `index.html` directly in a browser, or run a simple static web server in this folder.

## Deploy to Vercel

Import this repository in Vercel. Use the **Other** framework preset and leave the build command empty. The output directory is the project root.
